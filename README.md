# Arquivo Amaldiçoado

## Arquivos

- `index.html`: estrutura principal, navegação e janelas da página.
- `style.css`: cores, fontes, disposição dos elementos, adaptação para celular e impressão.
- `app.js`: personagens, cálculos, conteúdo das abas, rolagens, fotos e importação/exportação.

## Nomes usados no JavaScript

- `db`: conjunto de personagens salvos.
- `c`: personagem selecionado.
- `tab`: aba aberta.
- `fresh`: cria uma ficha.
- `save`: salva no navegador.
- `render`: atualiza a interface.
- `general`, `combat`, `cursed` e `record`: montam as abas.
- `radar`: desenha o gráfico.
- `skillTotal`: calcula o total de uma perícia.
- `roll`: faz a rolagem.
