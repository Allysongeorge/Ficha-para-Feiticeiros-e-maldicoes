# Arquivo Amaldiçoado

## Arquivos

- `index.html`: estrutura principal, navegação e janelas da página.
- `style.css`: cores, fontes, disposição dos elementos, adaptação para celular e impressão.
- `app.js`: personagens, cálculos, conteúdo das abas, rolagens, fotos e importação/exportação.

## Como editar

Abra esta pasta no VS Code. Mantenha os três arquivos juntos. Abra index.html no navegador para visualizar o projeto. Após editar, salve e atualize a página.

O JavaScript cria parte do HTML usando textos entre crases, chamados template literals. As expressões `${...}` inserem dados nesses textos. Alguns modelos de HTML continuam longos para preservar seu conteúdo original. Procure pelos nomes das funções e pelos comentários para localizar cada parte.

## Nomes usados no JavaScript

- `db`: conjunto de personagens salvos.
- `c`: personagem selecionado.
- `tab`: aba aberta.
- `fresh`: cria uma ficha.
- `save`: salva no navegador.
- `render`: atualiza a interface.
- `general`, `combat`, `cursed` e `record`: montam as abas.
- `radar`: desenha o gráfico.
- `skillTotal`: calcula o total de uma perícia.
- `roll`: faz a rolagem.

## Atualizar no GitHub Pages

Substitua index.html, style.css e app.js na raiz do repositório e confirme o envio com Commit changes. Aguarde a publicação e atualize o site. O arquivo LEIA-ME.md é opcional.

Esta versão altera formatação e comentários. A lógica e a chave de armazenamento foram preservadas. As fichas continuam locais ao navegador e ao endereço usado. Exporte seus personagens antes de trocar de navegador ou endereço.
